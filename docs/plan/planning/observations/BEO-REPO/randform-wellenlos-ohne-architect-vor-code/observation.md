# Ein wellenloser Slice erreicht den Architect vor dem Code nicht

**Sub-Area:** `*` (gesamtes Repo, Kürzel `REPO`)

Ein wellenloser Slice wird nicht über `plan-welle` bereitgestellt, und kein
Command-Schritt bringt ihn vor dem Code zum Architect. Nennt §6 die Randformen
eines neuen Vertrags gar nicht, greift vor dem Code nur die Rückgabe des
Implementers, und die nur, wenn er die Randform bemerkt; sonst findet sie erst
das Review.
