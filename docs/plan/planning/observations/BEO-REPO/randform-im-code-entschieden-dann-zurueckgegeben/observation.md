# Eine Randform wird erst im Code entschieden und danach zurückgegeben

**Sub-Area:** `*` (gesamtes Repo, Kürzel `REPO`)

Der Implementer bemerkt eine Randform, die §6 nicht entscheidet, setzt eine Lesart im
Code um und gibt sie im selben Commit an den Architect zurück, statt anzuhalten. Die
Rückgabe kommt an, aber nach der Entscheidung; der Architect bestätigt, was schon im
Code steht.
