**Stand:** gestrichen

Begründung: Die Ursache ist weggefallen. Die Beobachtung hängt an der Umstellung von White-Box- auf Black-Box-Tests, und die ist mit `slice-harness-blackbox-einstieg` abgeschlossen. Jede Testdatei des Moduls gehört zu einem `_test`-Paket (`make lint`: kein Befund in einer Testdatei, Verifikation zu `slice-harness-blackbox-einstieg`, Abschnitt 1). Was ein Test an Unexportiertem erreicht, steht je Paket in genau einer Datei `export_test.go` (`SPEC-049` Punkt 7), und der Compiler erzwingt das. Die Liste ist damit eine Datei und muss nicht mehr gesucht werden. `slice-harness-lint` schaltet `testpackage` am Gate scharf, und einen weiteren Umstellungs-Slice plant das Repo nicht. Steht ein Bestandsverzeichnis in §6 eines anderen Slice vor dem Code nur geschätzt, ist das eine andere Beobachtung und wird dort eingetragen.
