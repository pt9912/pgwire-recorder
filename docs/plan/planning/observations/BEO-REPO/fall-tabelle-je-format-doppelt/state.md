**Stand:** offen

1×; kein Ausgang, keine Adresse: Kein Folge-Slice führt eine geteilte Tabelle in §1 oder DoD (`AGENTS.md` §3.13), also ist `geplant` ohne Nehmer nicht möglich. Eine Adresse braucht den Eintrag im Nehmer im selben Commit; sie entsteht, wenn ein Slice eine dritte Tabelle derselben Fälle braucht. Der Nutzer kann entscheiden, ob dann ein Nehmer die Teilung übernimmt.
