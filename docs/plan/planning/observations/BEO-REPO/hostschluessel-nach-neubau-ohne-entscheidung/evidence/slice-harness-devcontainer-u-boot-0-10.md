**Vorgang:** slice-harness-devcontainer-u-boot-0-10
**Fund:** Im Gerüst auf `u-boot` 0.10.0 erzeugt das Feature `sshd` den Hostschlüssel im Build des Images (Fingerabdruck nennt `root@buildkitsandbox`). Neustart und neuer Container aus demselben Image ändern ihn nicht; ein Neubau mit `--build-no-cache` und der Neubau nach einer Änderung von `egress.allow` ergaben einen anderen Fingerabdruck, `ssh` meldete `WARNING: REMOTE HOST IDENTIFICATION HAS CHANGED!`. Die Proben liefen mit `UserKnownHostsFile` im Scratch; das Dokument empfiehlt keine Einstellung (`docs/developer/devcontainer.md` §5, §13). Entscheidung des Nutzers offen.
