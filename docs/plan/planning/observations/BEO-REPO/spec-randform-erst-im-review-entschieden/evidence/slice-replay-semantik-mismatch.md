**Fund:** §6 nannte vor dem Code die Randformen von `--fail-on-unconsumed`, nicht aber ihr Zusammenspiel mit der Hilfe und dem Ende der Optionen. Die Hilfe neben ungültiger Konfiguration fand erst das Review (F-382, HIGH; der Code entschied sie still). Vier Formen der Hilfe-Angabe (`--h`, vor dem Kommando, `=`-Wert, Wertstelle) gab der Implementer danach zurück (a205cbc). `--` an der Stelle eines Optionswerts fand erst die Verifikation (V-45). Drei Runden an derselben Regel `LH-FA-01.a` §Hilfe vor Prüfung; jede ging vor dem Code an den Architect, die erste Liste war unvollständig.
