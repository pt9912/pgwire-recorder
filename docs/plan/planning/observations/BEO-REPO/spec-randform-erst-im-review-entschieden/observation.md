# Eine Randform des Formats entscheidet erst das Review

**Sub-Area:** `*` (gesamtes Repo, Kürzel `REPO`)

Die Spezifikation eines neuen Formats lässt Randformen offen (fehlender Schlüssel,
`null`, leerer Wert, Alias, unbekanntes Feld); der Leser entscheidet sie still, und
erst Review oder Verifikation finden, dass Wortlaut und Leser auseinanderliegen —
Runde um Runde eine weitere Form.
