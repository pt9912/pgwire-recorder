# Eine Gate-Regel wird ersetzt statt ergänzt

**Sub-Area:** `*` (gesamtes Repo, Kürzel `REPO`)

Bei einer Änderung an einem Gate fällt eine bestehende Prüfung weg, weil die neue
Regel an ihre Stelle tritt statt neben sie: ein Modulpfad der `tech`-Regel wird
getauscht, eine Pflichtprüfung entfällt beim Umbau eines Skripts.
