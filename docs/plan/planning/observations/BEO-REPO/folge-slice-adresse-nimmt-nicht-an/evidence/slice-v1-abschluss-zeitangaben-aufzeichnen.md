Beide Bindungen trug der Planner bei der Closure in §1, §3, §4, §6 und §8 von `slice-v1-abschluss-sessions` ein (`3727254`), mit Nachzählung. Eine Bindung ist eine Sendung (`AGENTS.md` §3.13); der Eintrag fehlte im Geber.
