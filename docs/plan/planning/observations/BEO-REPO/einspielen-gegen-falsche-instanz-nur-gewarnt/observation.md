# Einspielen gegen eine falsche Instanz ist nur durch das Handbuch gewarnt

**Sub-Area:** `*` (gesamtes Repo, Kürzel `REPO`)

`play` führt die Anfragen einer Aufzeichnung gegen die angegebene Instanz aus und verändert
deren Inhalt. Gegen eine falsche Instanz (etwa eine produktive statt einer leeren) schützt
nichts im Produkt; das Benutzerhandbuch warnt (§4 *Eine Aufzeichnung in eine Datenbank
einspielen*), und das Lastenheft verlangt keinen Schutz. Wer eine Option, eine Umgebung oder
eine benannte Verbindung verwechselt, merkt es erst an der veränderten Datenbank.
