# Eine Klarstellung der Spezifikation im Slice löst den vorgemerkten Schnitt dem Wortlaut nach aus

**Sub-Area:** `*` (gesamtes Repo, Kürzel `REPO`)

Ein Plan merkt den Schnitt vor („ändert der Architect die Spezifikation im Slice, zählt sie als
dritte Schicht“) und unterscheidet nicht, ob die Änderung neuen Inhalt trägt oder nur festhält,
was der Code schon tut. Eine Klammer von drei Zeilen löst dann dem Wortlaut nach den Schnitt
aus, obwohl Größe und Prüfbarkeit, die der Schnitt schützt, unberührt sind; der Planner
entscheidet im Einzelfall, und `AGENTS.md` §3.13 nennt die Unterscheidung nicht.
