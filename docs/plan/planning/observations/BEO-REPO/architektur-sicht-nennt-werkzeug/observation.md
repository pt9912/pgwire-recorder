# Die Sicht nennt einen Werkzeugaufruf oder ein Sprach-Konstrukt

**Sub-Area:** `*` (gesamtes Repo, Kürzel `REPO`)

Ein Satz in `spec/architecture.md` trägt statt der Aussage den Aufruf, der sie prüft
(`go list -deps ./cmd/...`, „linkt“): ein sprachspezifisches Konstrukt im Sicht-Stratum,
das `AGENTS.md` §3.4 (meilenstein- und sprachfrei) ausschließt. Der Architect schreibt die
Stelle; das Review findet sie.
