# Eine Empfehlung eines Agenten wird als Entscheidung des Nutzers bezeichnet

**Sub-Area:** `*` (gesamtes Repo, Kürzel `REPO`)

Eine Entscheidung, die dem Nutzer gehört, steht in einem Plan oder Bericht als „Entscheidung
des Nutzers“, obwohl nur ein Agent (Architect, Implementer) sie empfohlen hat. Das Artefakt
behauptet eine Quelle, die es nicht gibt, und Review und Verifikation finden in keinem Artefakt
eine Entscheidung, gegen die sie die Umsetzung prüfen könnten.

Abgrenzung zu `BEO-REPO/plan-folgt-korrektur-nicht`: Dort bleibt eine Zeile nach einer
Korrektur auf dem alten Stand. Hier trägt die Zeile eine Herkunft, die nicht stimmt.
