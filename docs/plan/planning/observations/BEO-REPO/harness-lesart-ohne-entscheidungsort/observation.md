# Eine Lesart eines Harness-Vertrags hat keinen Entscheidungsort

**Sub-Area:** `*` (gesamtes Repo, Kürzel `REPO`)

Für Harness-Gates gibt es keine Spezifikation, und eine angenommene ADR ist gesperrt.
`AGENTS.md` §3.12 verlangt die Entscheidung einer Randform in Spezifikation oder ADR,
§3.8 hält Regeldetails aus der ADR heraus. Lesarten des ADR-Wortlauts landen darum im
Slice-Plan und im Skript-Kopf, auch solche, die eher eine Wahl als eine Präzisierung
sind.
