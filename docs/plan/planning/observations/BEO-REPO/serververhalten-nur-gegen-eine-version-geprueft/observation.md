# Verhalten des Servers nur gegen eine Version geprüft

**Sub-Area:** `*` (gesamtes Repo, Kürzel `REPO`)

Das Produkt bildet eine Eigenschaft von PostgreSQL nach oder setzt sie voraus; die
Eigenschaft hängt an der Serverversion, Spezifikation und Gate kennen aber nur die
gepinnte Version, und erst ein Review oder eine Sonde gegen eine andere findet die
Abweichung.
