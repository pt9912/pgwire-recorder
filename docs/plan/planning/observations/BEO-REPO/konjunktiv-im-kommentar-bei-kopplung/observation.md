# Ein Kommentar nennt eine Kopplung im Konjunktiv über den Fehlerfall

**Sub-Area:** `*` (gesamtes Repo, Kürzel `REPO`)

Ein Kommentar trägt eine Kopplung (der Test hängt am Verhalten des Servers), formuliert sie
aber als „wäre“ über den Fall, der nicht eintritt. `AGENTS.md` §3.7 verlangt den Indikativ über
den Zustand. Der Reviewer liest den Satz als Kopplung, die Form bleibt ein Hinweis.
