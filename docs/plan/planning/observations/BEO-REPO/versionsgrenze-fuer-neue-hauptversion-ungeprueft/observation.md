# Die Versionsgrenze der Lebendprüfung ist für eine neue Hauptversion ungeprüft

**Sub-Area:** `*` (gesamtes Repo, Kürzel `REPO`)

Die Erkennung der Lebendprüfung hängt von `server_version` ab (`\v` ist ab 17 Leerraum). Die Grenze ist durch Sonde und Matrix für die Liste belegt; eine Hauptversion außerhalb der Liste kann sie anders ziehen, und erst der Lauf der Matrix gegen sie zeigt es.
