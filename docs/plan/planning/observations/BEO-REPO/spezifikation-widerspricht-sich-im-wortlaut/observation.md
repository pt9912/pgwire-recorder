# Die Spezifikation sagt dasselbe an zwei Stellen verschieden

**Sub-Area:** `*` (gesamtes Repo, Kürzel `REPO`)

Zwei Abschnitte derselben Anforderung nennen denselben Gegenstand mit verschiedenem Wortlaut
(etwa den Beginn einer Messung); der Code folgt dem genaueren, der kürzere Satz widerspricht
ihm, und ein Leser, der nur diesen liest, erwartet anderes. Erst die Verifikation, die Wortlaut
gegen Binary hält, findet es; ein Test prüft nur eine der beiden Aussagen.

Abgrenzung zu `BEO-REPO/spec-randform-erst-im-review-entschieden`: Dort ist eine Randform
unentschieden; hier ist sie entschieden, an zwei Stellen verschieden.
